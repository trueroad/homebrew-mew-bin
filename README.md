# Homebrew mew-bin (Binary of Messaging in the Emacs World)

## install binary

```
brew tap trueroad/mew-bin
brew trust --formula trueroad/mew-bin/mew-bin
brew install mew-bin
```

If you want to install unstable version.

```
brew install --HEAD mew-bin
```
